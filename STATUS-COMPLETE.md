## How to read this document

| Column       | Meaning                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------- |
| **ID**       | Stable key (`S0`, `G7`, `RQ-LINK`, …) used by release automation and doc-audit            |
| **Status**   | `done` when evidence is recorded here; `open` / `planned` / `deferred` in other registers |
