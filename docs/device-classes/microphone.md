## 3. Data flow

Control (`open`, `close`, `configure`, `read`, low-rate `subscribe`) stays on the
broker. Sample data uses the device stream sidecar after the broker authorizes a
session. Preview surfaces the host draws are not readable back by the sandbox.

| Field | Value |
| ----- | ----- |
| Streamable to a peer | yes |
| Remote-eligible | yes |
| Max rate | 50 Hz |
| Session TTL | 900000 ms |
| Duty cycle | — |

Streaming additionally requires `device:stream`. A peer acquiring this class on
this host additionally requires `device:remote` on the requesting side and a
host-owned remote grant on the serving side.

## 5. Degradation ladder

Highest fidelity first. Admission walks down this list when supply cannot hold
the current rung.

- `48k-pcm`
- `16k-opus`
- `8k-narrowband`
- `vad-transcript`
