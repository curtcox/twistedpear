When you use your phone to do something, it often uses far away computers that have no real logical need to be involved.
The goal of this project is to give people a choice about if and when those extaneous computers are involved.
In a world where it is widely adopted, users always know who is involved in the things they are doing.
Whenever they don't know, they can easily find out.

The goal of TwistedPair is to provide a platform for users to run apps that do any sort of activitiy they might want to do on their phones.
Unlike other platforms, users can always examine the source code of the program before running it.
There is no central authority that determines if a program is safe.
However, many safegards are built into the platform to help ensure that runninng a dangerous program by accident is essentially impossible.
Programs must publish their source code, be signed by their author, be written by a trusted author, tell the user beforehand what resources they need access to (like the camera) and why.

There is no intention to make money for the platform providers or the application authors.
There is no intention to market the platform beyond whatever viral disemination happens as a byproduct of satisfied users.
